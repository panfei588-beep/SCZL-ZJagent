# 航天质量改善数字专家 - 技术文档

## 1. 项目概述

本系统是面向航天阀门生产制造质检部门的 AI 智能体应用，基于"人机料法环测"六维分析框架，实现质量异常的自动诊断和改进方案生成。

**核心能力：**

- 多格式文件解析（PDF/图片/Excel/Word），使用 MinerU 进行 OCR 识别
- LangGraph StateGraph 编排 6 个智能体节点协同工作（数据分析 → 校验 → 诊断 → 校验 → 决策 → 输出整合）
- Milvus 双向量知识库检索（诊断知识库 + 改善知识库）
- Qwen 大模型进行深度根因推理
- 自动生成带优先级和 ROI 的改进方案
- 数据校验与重试机制（最多 3 次回退）
- 置信度评估与低置信警告
- matplotlib 自动生成统计图表

## 4. MinerU 集成说明

MinerU 是上海人工智能实验室开源的文档解析工具，本项目用于解析用户上传的质量检测报告。

**支持格式：** PDF、图片（JPG/PNG）、Word（DOCX）、Excel（XLSX）、PPT（PPTX）

**集成方式：** pip 安装，直接在后端 Python 服务中调用

```python
from mineru.api import MinerUAPI

api = MinerUAPI()
result = api.parse(file_path)  # 返回 Markdown + JSON 结构化内容
```

**解析流程：**

1. 用户上传文件 → FastAPI 接收并保存
2. 调用 MinerU 解析 → 提取文本、表格、图片内容
3. 结构化提取质量检测记录（日期、产品号、检测项、实测值、判定）
4. 传入 LangGraph data_agent 节点进行分析

## 5. LangGraph 工作流程

### 5.1 6 个节点概览

| 节点 | 职责 | 输出到 State |
| --- | --- | --- |
| **data_agent** | 解析文件 → 统计计算(max/min/mean/std/包络线) → 生成图表 | parsed_data, statistics, charts |
| **validate_data** | 字段完整性/数值范围/时间连续性校验 | data_valid, data_retry_count |
| **diagnosis_agent** | RAG 检索(诊断KB, k=5) + Qwen LLM 推理 → 6维根因 | diagnosis_result, diagnosis_confidence |
| **validate_diagnosis** | 置信度>0.6 + KB 引用检查 | diagnosis_valid, low_confidence_flag |
| **decision_agent** | RAG 检索(改善KB, k=5) + Qwen LLM 推理 → 改进方案 | improvement_plan, estimated_improvement |
| **output_merger** | 汇总所有结果 | final_output |

### 5.2 条件边路由

```text
data_agent → validate_data
  ├── data_valid=True → diagnosis_agent
  ├── data_valid=False & retry<3 → data_agent（回退重试）
  └── data_valid=False & retry≥3 → diagnosis_agent（降级继续）

diagnosis_agent → validate_diagnosis → decision_agent（始终继续，低置信打标）

decision_agent → output_merger → END
```

### 5.3 State 定义

```python
class QualityAgentState(TypedDict):
    raw_file_path: str                       # 上传文件路径
    user_params: dict                        # 用户选项参数
    parsed_data: Optional[dict]              # 解析后的结构化数据
    statistics: Optional[dict]               # max/min/mean/std/包络线
    charts: Optional[list]                   # 图表文件路径列表
    data_valid: Optional[bool]               # 数据校验结果
    data_retry_count: int                    # 数据解析重试次数
    diagnosis_result: Optional[list]         # 诊断原因列表
    diagnosis_confidence: Optional[float]    # 置信度 0~1
    diagnosis_has_kb_ref: Optional[bool]     # 是否有知识库依据
    diagnosis_valid: Optional[bool]          # 诊断校验结果
    low_confidence_flag: Optional[bool]      # 低置信度预警标记
    improvement_plan: Optional[list]         # 改进方案列表
    estimated_improvement: Optional[str]     # 预估提升效果
    final_output: Optional[dict]             # 最终输出
    error_message: Optional[str]             # 异常信息
```

### 5.4 关键参数

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 置信度阈值 | 0.6 | 低于 0.6 标记低置信警告，不阻断流程 |
| 数据重试次数 | 3 | 数据校验失败最多回退重试 3 次 |
| RAG 检索条数 k | 5 | 诊断/改善知识库各检索 top-5 |
| 包络线计算 | mean ± 3*std | 样本<20 时改为 2*std，<5 时不画 |

## 6. 知识库设计

### 6.1 双知识库架构

| 知识库 | Collection 名称 | 用途 | 向量化内容 |
| --- | --- | --- | --- |
| 诊断知识库 | `diagnosis_cases` | Agent2 根因分析时 RAG 检索 | title + problem + root_cause |
| 改善知识库 | `improvement_cases` | Agent3 方案生成时 RAG 检索 | title + solution + effect |

### 6.2 数据来源

从 `backend/data/cases/quality_cases.json` 的 10 条预置案例拆分导入：

- CASE-001 ~ CASE-010 覆盖 6 个维度（人/机/料/法/环/测）
- 诊断库提取 problem + root_cause 部分
- 改善库提取 solution + effect 部分

### 6.3 检索方式

- Embedding 模型：DashScope `text-embedding-v2`
- 检索接口：`search_diagnosis_cases(query, top_k=5)` / `search_improvement_cases(query, top_k=5)`
- 相似度计算：`1 - score`（LangChain 向量距离转相似度）
- Fallback：Milvus 不可用时返回空列表，不阻断流程

## 7. 图表生成

### 7.1 图表类型

| 图表 | 生成函数 | 用途 |
| --- | --- | --- |
| 合格率趋势图 | `generate_trend_chart()` | 显示每日合格率变化 + 包络线 |
| 数据分布图 | `generate_distribution_chart()` | 数值列直方图 + 均值/3σ 线 |

### 7.2 输出格式

- 格式：PNG 图片，dpi=120
- 目录：`backend/charts/`
- 文件名：`trend_{uuid}.png` / `distribution_{uuid}.png`
- 前端访问：`/api/static/charts/{filename}`

### 7.3 中文字体

Dockerfile 安装 `fonts-noto-cjk`，matplotlib 设置 `Noto Sans CJK SC` 字体，避免中文显示为方块。

## 8. 部署指南

### 前置条件

- Ubuntu 20.04+ / CentOS 7+
- Docker 20.10+
- Docker Compose 2.0+
- 内存 ≥ 8GB（MinerU pipeline 模式）
- 磁盘 ≥ 40GB（含 MinerU 模型文件约 5GB）

### 快速部署

```bash
# 1. 克隆项目
git clone <repo_url>
cd 航天运载火箭智能体/deploy

# 2. 配置环境变量
cp .env.example .env
vim .env  # 填入 DASHSCOPE_API_KEY

# 3. 一键部署
chmod +x deploy.sh
./deploy.sh

# 4. 初始化双知识库（首次部署）
docker exec quality-backend python data/init_knowledge_base.py
```

1. 访问 <https://dashscope.aliyun.com/>
2. 注册/登录阿里云账号
