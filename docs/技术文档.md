# 航天运载火箭质量异常诊断数字员工 - 技术文档

## 1. 项目概述

本系统是面向航天运载火箭制造质检部门的 AI 智能体应用，基于"人机料法环测"六维分析框架，实现质量异常的自动诊断和改进方案生成。

**核心能力：**
- 多格式文件解析（PDF/图片/Excel/Word），使用 MinerU 进行 OCR 识别
- LangChain 编排三个专业 Agent 协同工作
- Milvus 向量数据库检索相似历史案例
- Qwen 大模型进行深度根因推理
- 自动生成带优先级和 ROI 的改进方案

## 4. MinerU 集成说明

MinerU 是上海人工智能实验室开源的文档解析工具，本项目用于解析用户上传的质量检测报告。

**支持格式：** PDF、图片（JPG/PNG）、Word（DOCX）、Excel（XLSX）、PPT（PPTX）

**集成方式：** pip 安装，直接在后端 Python 服务中调用

```python
from mineru.api import MinerUAPI

api = MinerUAPI()
result = api.parse(file_path)  # 返回 Markdown + JSON 结构化内容
```

**解析流程：**
1. 用户上传文件 → FastAPI 接收并保存
2. 调用 MinerU 解析 → 提取文本、表格、图片内容
3. 结构化提取质量检测记录（日期、产品号、检测项、实测值、判定）
4. 传入 LangChain Agent 进行分析

## 5. Agent 工作流程

```
用户上传文件
    ↓
数据采集 Agent
    ├── MinerU 解析文件（PDF/图片/Word）
    ├── pandas 解析 Excel
    └── 数据清洗、标准化
    ↓
诊断专家 Agent
    ├── analyze_quality_trend（趋势分析）
    ├── search_similar_cases（Milvus 检索）
    ├── llm_root_cause_analysis（6维根因分析）
    └── Qwen 大模型深度推理
    ↓
决策支持 Agent
    ├── generate_improvement_plan（生成方案）
    └── calculate_roi（ROI 计算）
    ↓
返回结构化诊断报告
```

## 6. 部署指南

### 前置条件

- Ubuntu 20.04+ / CentOS 7+
- Docker 20.10+
- Docker Compose 2.0+
- 内存 ≥ 8GB（MinerU pipeline 模式）
- 磁盘 ≥ 40GB（含 MinerU 模型文件约 5GB）

### 快速部署

```bash
# 1. 克隆项目
git clone <repo_url>
cd 航天运载火箭智能体/deploy

# 2. 配置环境变量
cp .env.example .env
vim .env  # 填入 DASHSCOPE_API_KEY

# 3. 一键部署
chmod +x deploy.sh
./deploy.sh

# 4. 初始化知识库（首次部署）
docker exec quality-backend python data/init_knowledge_base.py
```

### 获取 DashScope API Key

1. 访问 https://dashscope.aliyun.com/
2. 注册/登录阿里云账号
3. 开通通义千问服务
4. 在 API-KEY 管理页面创建 Key
